# 版式参数与物件选择

以下尺寸以 1280 × 720、96 DPI 的画布为例，单位是 CSS px。使用其他画布时等比换算，不把像素数直接当成 pt。

## 字号与留白

- 内容边距通常 78–96 px。
- 页标题通常 50–56 px，正文 29–34 px，辅助标签 22–27 px。
- 封面主标题 76–96 px，可拆成两个独立文本框控制断行。
- 注释较多时先精简句子，不通过不断缩字号解决拥挤。
- 标题后留出空间再进入图解。页脚不是必需项，避免无关的标签、编号和口号。

## 大字开场

左侧一句主题，通常占宽度的约三分之二。粉色副标题只补充一个意思。右下角放一个 250–320 px 的贴纸，保持大块白色空间。

主标题自然换行，不把完整文章标题缩成一行。中文使用正常标点；英文短标签可沿用轻松的手写语气。

## 关系图

标题在上，主体是一个真实关系：分支、汇合、因果或层级。每个框只写对象或动作，说明贴近对应框，连接线在说明外面走。

例如“原始材料”进入“重述问题”，再分成“已确认事实 / 可能原因 / 待验证”。这个例子展示的是信息如何分开，不表示所有演示都需要三分支。

## 流程图

横向铺开能读清的步骤，一般 3–4 个。每步一个短标签，下面一行说明。超过一行容纳量时拆页，避免蛇形回绕。

可在下半页放一句来自材料的结论，以及一个较小的对应物件。结论与流程有重复时，删去重复的副标题或结论。

## 物件提问页

左边一个 330–430 px 的大贴纸，右边一个问题和一句回答。粉色说明放在回答下方，保持与问题的层级差别。这适合换章节、解释关键选择或收束主题。

## 贴纸与语义

| 讲解内容 | 可用物件 |
|---|---|
| 想法、发现 | 灯泡 `lightbulb` |
| 观察、查证、理解问题 | 放大镜 `magnifier` |
| 复用、组合、适配 | 拼图 `puzzle` |
| 原型、试验、第一次尝试 | 纸飞机 `paper-plane` |
| 路径、方向、取舍 | 旗帜 `flag`、台阶 `steps` |
| 设计、修改、草案 | 铅笔 `pencil` |
| 反馈、讨论 | 对话框 `chat` |
| 长期维护、成长 | 幼苗 `seedling` |

选择与材料相关的物件，不把这张对应表当作固定的页面清单。贴纸轮廓较粗，展示尺寸通常比原有全身人物更小，替换时重新判断图片的视觉重量。
